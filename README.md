# plugins_tessera

Plugins for [Tessera](https://github.com/MaxGramser/tessera-plugins), the ESP32 touch screens for Home Assistant.

| Plugin | What it does | Add in Tessera with |
|---|---|---|
| [proxmox](plugins/proxmox) | A Proxmox node's status, CPU, memory and disk, and a status list of guests or services | `https://github.com/willobarboza/plugins_tessera/tree/main/plugins/proxmox` |
| [creality](plugins/creality) | A Creality 3D printer (K1, K2, Ender 3 V3...): how the print goes, temperatures, and keys to pause, resume and stop | `https://github.com/willobarboza/plugins_tessera/tree/main/plugins/creality` |
| [jellyfin](plugins/jellyfin) | What plays on your Jellyfin clients, a control card (play, pause, seek, stop, volume, mute) and your libraries to browse and play | `https://github.com/willobarboza/plugins_tessera/tree/main/plugins/jellyfin` |
