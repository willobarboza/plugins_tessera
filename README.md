# plugins_tessera

Plugins for [Tessera](https://github.com/MaxGramser/tessera-plugins), the ESP32 touch screens for Home Assistant.

| Plugin | What it does | Add in Tessera with |
|---|---|---|
| [proxmox](plugins/proxmox) | A Proxmox node's status, CPU, memory and disk, and a status list of guests or services | `https://github.com/willobarboza/plugins_tessera/tree/main/plugins/proxmox` |
